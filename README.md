## О проекте

Приложение представляет собой будильник с возможностью сохранения пресетов времени и добавления звуков и мелодий звонка. Помимо будильника в приложении также доступны часы и секундомер.  
Проект был выполнен в качестве практического задания с целью изучения основ WPF и паттерна MVVM.

## Схема приложения

**Приложение состоит из 3-ёх главных разделов:**  
1. *Часы*  
2. *Секундомер*  
3. *Будильник*  

**Особенностью приложения является список пресетов времени, а также список добавленных звуков и мелодий. Выбранная мелодия будет проигрываться по срабатывании будильника.**
